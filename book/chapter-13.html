۱. متغیرهای CSS

تا اینجا هر بار رنگ سایت را دستی نوشتیم. اگر بخواهید رنگ اصلی سایتتان را عوض کنید، باید ده‌ها جا را تغییر دهید و حتماً یکی دو مورد را فراموش می‌کنید. متغیر این مشکل را کاملاً حل می‌کند. 

:root {
    --primary: #2f4f4f;
    --primary-dark: #223a3a;
    --accent: #ff6347;
    --bg-light: #f5f5f5;
    --text: #333333;
    --muted: #777777;
    --border: #e0e0e0;
    --radius: 10px;
    --space: 20px;
}

body {
    background-color: var(--bg-light);
    color: var(--text);
}

.btn {
    background-color: var(--primary);
    border-radius: var(--radius);
    padding: 12px var(--space);
}

.btn:hover {
    background-color: var(--accent);
}

متغیرها: نمونه 01-css-variables

شرح مثال

  • root: یک شبه‌کلاس است که به ریشه سند اشاره می‌کند، یعنی تگ html. متغیرهایی که اینجا تعریف شوند، در کل صفحه در دسترس‌اند.
  • نام هر متغیر حتماً با دو خط تیره شروع می‌شود. این اجباری است، نه سلیقه‌ای.
  • برای استفاده، نام متغیر را داخل var() می‌گذاریم.

حالا برای عوض کردن رنگ اصلی کل سایت، تنها یک خط در بالای فایل تغییر می‌کند و همه جا با هم به‌روز می‌شود.

چه چیزهایی را متغیر کنیم

هر چیزی که بیش از دو بار تکرار می‌شود: رنگ‌ها، گردی گوشه‌ها، فاصله استاندارد، سایه‌ها. اگر عددی تنها یک بار در کل فایل استفاده می‌شود، نیازی به متغیر ندارد.

۲. سایه

سایه به عنصرها عمق می‌دهد و باعث می‌شود کارت‌ها انگار روی صفحه شناور باشند. این ساده‌ترین راه حرفه‌ای‌تر کردن یک طرح است. 

.card {
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

.card-hover {
    box-shadow: 0 8px 20px rgba(0, 0, 0, 0.15);
}

.inner {
    box-shadow: inset 0 2px 5px rgba(0, 0, 0, 0.2);
}

.title {
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}

سایه: نمونه 02-shadow

شرح مثال

box-shadow چهار مقدار می‌گیرد:

مقدارمعنی
اولجابه‌جایی افقی سایه
دومجابه‌جایی عمودی. مثبت یعنی سایه به پایین.
سوممیزان محو شدن. عدد بزرگ‌تر یعنی سایه نرم‌تر.
چهارمرنگ سایه

کلمه inset در ابتدا، سایه را به داخل جعبه می‌برد و حس فرورفتگی می‌دهد. text-shadow هم دقیقاً همین‌طور کار می‌کند اما برای متن، و مقدار inset ندارد.

راز سایه‌های خوب

سایه‌های زیبا ملایم هستند. از رنگ سیاه با شفافیت کم استفاده کنید، نه از خاکستری توپر. rgba(0, 0, 0, 0.1) یعنی سیاه با ده درصد ماندگاری، که زیر آن هر رنگی باشد طبیعی به نظر می‌رسد. سایه‌های تیره و تند، طرح را قدیمی نشان می‌دهند.

گرادیانت و شفافیت: نمونه 03-gradient-opacity

شرح مثال

linear-gradient یک تصویر می‌سازد که از یک رنگ به رنگ دیگر محو می‌شود. اولین مقدار جهت است و بقیه رنگ‌ها. چون یک تصویر است، در background-image نوشته می‌شود، نه در background-color.

opacity شفافیت کل عنصر را تنظیم می‌کند: عدد ۱ یعنی کاملاً مات و ۰ یعنی کاملاً نامرئی. نکته مهم اینکه این ویژگی روی همه چیز اثر می‌گذارد، از جمله متن داخل عنصر. اگر تنها پس‌زمینه را می‌خواهید شفاف کنید، از rgba استفاده کنید.

rgba همان rgb است با یک عدد چهارم: میزان ماندگاری از صفر تا یک. پس rgba(0, 0, 0, 0.5) یعنی سیاه نیمه‌شفاف.

مهم‌ترین تکنیک این بخش

بخش سوم مثال، تکنیکی است که تقریباً هر سایتی از آن استفاده می‌کند: پرده تیره روی عکس. یک گرادیانت که هر دو رنگش یکسان و نیمه‌شفاف است، مانند یک شیشه دودی روی عکس عمل می‌کند. نتیجه‌اش این است که متن سفید روی هر عکسی خوانا می‌ماند. دقت کنید که گرادیانت قبل از عکس نوشته می‌شود، چون لایه‌های پس‌زمینه از بالا به پایین چیده می‌شوند. در فصل بعد دقیقاً از همین کد برای هدر پروژه استفاده می‌کنیم.

transform: نمونه 04-transform

شرح مثال

تابعکارش
translateX و translateYجابه‌جایی افقی و عمودی
scaleبزرگ یا کوچک کردن. عدد ۱ یعنی اندازه اصلی.
rotateچرخاندن بر حسب درجه

می‌شود چند تابع را با فاصله پشت سر هم نوشت و همه با هم اعمال می‌شوند. اما دقت کنید که نمی‌توانید دو خط transform جدا بنویسید؛ دومی اولی را پاک می‌کند.

چرا transform بهتر از تغییر مستقیم است

برای بالا بردن یک کارت می‌شد margin-top منفی هم داد، اما آن کار باعث می‌شود بقیه عنصرهای صفحه جابه‌جا شوند و چیدمان تکان بخورد. transform تنها نمایش عنصر را عوض می‌کند و جای واقعی‌اش دست‌نخورده می‌ماند. به‌علاوه مرورگر برای آن از کارت گرافیک استفاده می‌کند و حرکت بسیار نرم‌تر است.

transform تقریباً همیشه همراه transition و hover: می‌آید. سه خط آخر مثال، پرکاربردترین الگوی افکت کارت در کل طراحی وب است.

۵. object-fit و calc

.card-image {
    width: 100%;
    height: 200px;
    object-fit: cover;
}

.logo {
    width: 100px;
    height: 100px;
    object-fit: contain;
}

.full-bleed {
    width: calc(100% + 40px);
    margin-right: -20px;
    margin-left: -20px;
}

.main-area {
    width: calc(100% - 250px);
}

object-fit و calc: نمونه 05-object-fit-calc

شرح مثال

مشکل: در یک ردیف کارت، عکس‌ها اندازه‌های مختلفی دارند و کارت‌ها نامرتب می‌شوند. اگر عرض و ارتفاع ثابت بدهید، عکس‌ها کشیده و بدشکل می‌شوند.

راه‌حل: object-fit که دقیقاً مانند background-size عمل می‌کند، اما روی تگ img:

  • cover کادر را کامل پر می‌کند و نسبت تصویر را حفظ می‌کند. لبه‌ها بریده می‌شوند. برای عکس کارت‌ها همیشه همین را بخواهید.
  • contain کل تصویر را نشان می‌دهد و ممکن است فضای خالی بماند. برای لوگو مناسب است.

calc() اجازه می‌دهد داخل CSS محاسبه کنید، حتی بین واحدهای متفاوت. این کاری است که هیچ راه دیگری برای انجامش نیست: مرورگر نمی‌داند صد درصد چند پیکسل است، اما calc در لحظه نمایش حسابش می‌کند.

فاصله دور علامت‌ها اجباری است

calc(100% - 250px) درست است، اما calc(100%-250px) اصلاً کار نمی‌کند. دور علامت‌های جمع و تفریق حتماً باید فاصله باشد.

ترکیب calc با حاشیه منفی، تکنیک «تصویر تمام‌عرض کارت» را می‌سازد: تصویر از لبه تا لبه کارت کشیده می‌شود و padding کارت را نادیده می‌گیرد.

۶. شبه‌کلاس‌های پیشرفته

تا اینجا تنها hover: و focus: را دیدیم. چند شبه‌کلاس دیگر هم هستند که بر اساس جایگاه عنصر انتخاب می‌کنند.

li:first-child {
    font-weight: bold;
}

li:last-child {
    border-bottom: none;
}

tr:nth-child(odd) {
    background-color: #f7f7f7;
}

tr:nth-child(even) {
    background-color: white;
}

li:nth-child(3) {
    color: #ff6347;
}

input:focus {
    border-color: #2f4f4f;
}

.btn:active {
    transform: scale(0.97);
}

شبه‌کلاس‌های پیشرفته: نمونه 06-pseudo-class-advanced

شرح مثال

شبه‌کلاسانتخاب می‌کند
:first-childاولین فرزند والدش
:last-childآخرین فرزند
:nth-child(odd)فرزندان فرد: اول، سوم، پنجم
:nth-child(even)فرزندان زوج
:nth-child(3)دقیقاً سومی
:focusعنصری که نشانگر داخلش است
:activeلحظه‌ای که کاربر کلیک را نگه داشته

nth-child(odd): پرکاربردترینشان است و جدول راه‌راه می‌سازد که خواندن سطرهایش بسیار آسان‌تر است. last-child: هم برای برداشتن خط جداکننده آخرین مورد یک فهرست عالی است، تا خط اضافه‌ای زیر فهرست نماند.

active: حس فشرده شدن دکمه را می‌دهد. کوچک کردن بسیار جزئی دکمه در لحظه کلیک، بازخوردی است که کاربر آن را نمی‌بیند اما حس می‌کند.

۷. شبه‌عنصرها

شبه‌کلاس یک عنصر موجود را انتخاب می‌کند. شبه‌عنصر یک قطعه تازه می‌سازد که در HTML وجود ندارد. علامتش دو تا دو نقطه است. 

.section-title {
    position: relative;
    padding-bottom: 12px;
}

.section-title::after {
    content: "";
    position: absolute;
    right: 0;
    bottom: 0;
    width: 60px;
    height: 4px;
    background-color: var(--accent);
    border-radius: 2px;
}

.new-card::before {
    content: "جدید";
    position: absolute;
    top: 10px;
    left: 10px;
    background-color: var(--accent);
    color: white;
    padding: 4px 12px;
    border-radius: 20px;
    font-size: 13px;
}

.check-list li::before {
    content: "✔ ";
    color: green;
}

شبه‌عنصرها: نمونه 07-pseudo-element

شرح مثال

  • before:: قطعه‌ای قبل از محتوای عنصر می‌سازد و after:: بعد از آن.
  • ویژگی content اجباری است. بدون آن، شبه‌عنصر اصلاً ساخته نمی‌شود، حتی اگر ده خط استایل دیگر برایش بنویسید. اگر تنها شکل می‌خواهید و نه متن، بنویسید content: "".
  • شبه‌عنصر بخشی از عنصر والد است، پس با position: absolute داخل والدِ relative جای می‌گیرد. همان الگوی فصل نهم.
چرا این مهم است

آن خط تزیینی نارنجی زیر عنوان‌ها، بدون شبه‌عنصر نیاز به یک div خالی و بی‌معنی در HTML داشت. با after:: عنصر تزیینی در جای درست خودش یعنی CSS می‌ماند و HTML تمیز باقی می‌ماند. قانون کلی این است: هر چیزی که تنها تزیین است، در CSS ساخته شود نه در HTML.

نکته‌های تکمیلی: نمونه 08-extra-touches

شرح مثال

  • لینک داخلی. اگر href با # شروع شود، به عنصری با همان id در همان صفحه می‌رود. اینجاست که آی‌دی فصل سوم به کار می‌آید.
  • scroll-behavior: smooth باعث می‌شود این پرش به جای ناگهانی بودن، نرم و روان انجام شود. یک خط، تأثیر بسیار.
  • mailto: برنامه ایمیل کاربر را باز می‌کند و tel: روی گوشی شماره‌گیر را. برای صفحه تماس بسیار مفیدند.
  • cursor: pointer شکل موس را به دست تبدیل می‌کند. روی هر چیزی که قابل کلیک است و لینک یا دکمه نیست، لازم است.
  • filter جلوه‌های تصویری می‌سازد. grayscale سیاه‌وسفید می‌کند و blur محو. ترکیب سیاه‌وسفید با hover: که رنگ را برمی‌گرداند، برای گالری‌ها جلوه زیبایی می‌سازد.
دو تگ فراموش‌شده در head

<title> عنوان سربرگ مرورگر است و در نتایج گوگل هم به عنوان تیتر آبی نمایش داده می‌شود. <meta name="description"> هم آن متن توضیحی زیر تیتر است. هر صفحه باید هر دو را داشته باشد و محتوایشان باید برای هر صفحه متفاوت باشد.

نمونه نهایی فصل: نمونه 09-final-example

شرح مثال

این صفحه تقریباً هر چیزی را که در این فصل خواندیم به کار می‌برد و شکل و حال یک سایت واقعی و امروزی را دارد.

  • متغیرها. هیچ رنگی در فایل به شکل دستی نوشته نشده، حتی سایه‌ها هم متغیر شده‌اند. برای عوض کردن تم کل صفحه، تنها بلوک root: تغییر می‌کند.
  • هدر بزرگ. ترکیب گرادیانت نیمه‌شفاف روی عکس، به‌علاوه فلکس‌باکس برای وسط‌چین کردن، به‌علاوه text-shadow تا متن روی هر عکسی خوانا بماند.
  • دکمه. سه حالت دارد: عادی، بزرگ‌شونده در hover: و کمی فشرده در active:. به‌علاوه لینک داخلی به بخش رشته‌ها که با scroll-behavior: smooth نرم اسکرول می‌کند.
  • عنوان بخش. خط تزیینی نارنجی با after:: ساخته شده، بدون هیچ تگ اضافه‌ای در HTML.
  • کارت‌ها. تصویرها با object-fit: cover هم‌اندازه شده‌اند، در hover: کارت بالا می‌آید و سایه‌اش بزرگ‌تر می‌شود و رنگ عکس هم برمی‌گردد. نشان «جدید» هم یک before:: است.
  • فهرست. تیک سبز هر مورد با before:: آمده و خط زیر آخرین مورد با last-child: برداشته شده است.
یک نکته تازه در گرید

در بخش کارت‌ها نوشته‌ایم repeat(auto-fit, minmax(240px, 1fr)). معنی‌اش این است: «هر چند ستون که جا می‌شود بساز، به شرطی که هیچ ستونی باریک‌تر از ۲۴۰ پیکسل نشود». نتیجه‌اش یک گالری کاملاً واکنش‌گراست، بدون حتی یک media query. این پیشرفته‌ترین نکته این کتاب است و اگر آن را به خاطر بسپارید، در پروژه‌های واقعی بسیار به کارتان می‌آید.

تمرین‌های فصل سیزده

  1. فایل CSS یکی از تمرین‌های قبلی را بردارید و همه رنگ‌هایش را به متغیر تبدیل کنید. بعد با عوض کردن یک خط، تم کل صفحه را تغییر دهید.
  2. یک هدر بزرگ با عکس و پرده تیره بسازید که متن سفیدش کاملاً خوانا باشد.
  3. کارتی بسازید که با رفتن موس روی آن، بالا بیاید و سایه‌اش بزرگ‌تر شود.
  4. زیر همه عنوان‌های بخش، یک خط تزیینی با after:: اضافه کنید.
  5. یک جدول راه‌راه با nth-child(odd): بسازید.
  6. یک گالری با repeat(auto-fit, minmax(240px, 1fr)) بسازید و پنجره را باریک کنید تا رفتارش را ببینید.
  7. تصویرهایی با اندازه‌های مختلف در کارت‌ها بگذارید و با object-fit: cover مرتبشان کنید.
