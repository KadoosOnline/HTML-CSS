راهنمای طراحی سایت دبیرستان دانش

پیش از ساخت صفحات، ابتدا زبان بصری سایت (رنگ‌ها، فونت، دکمه‌ها و کارت‌ها) را در قالب CSS طراحی می‌کنیم. سپس در صفحات HTML از همین کلاس‌ها استفاده خواهیم کرد.

همان‌طور که در جلسه ۱۳ یاد گرفتیم، همه رنگ‌ها را به شکل متغیر در root: تعریف می‌کنیم. اگر بعداً بخواهیم رنگ سایت را عوض کنیم، فقط چند خط بالای فایل CSS تغییر می‌کند و کل هفت صفحه سایت به‌روز می‌شود.

رنگ‌های اصلی

primary-- #2f4f4f
primary-dark-- #1c3333
accent-- #ff6347
bg-light-- #f5f5f5
