لینک داخلی cursor filter لینک خارجی

۱. لینک داخل همان صفحه + اسکرول نرم

اگر به یک عنصر id بدهیم، می‌توانیم با href="#id" به آن لینک بدهیم. با scroll-behavior: smooth روی html، پرش صفحه نرم می‌شود. روی لینک‌های بالای صفحه کلیک کنید.

۲. شکل نشانگر موس (cursor)

موس را روی جعبه‌ها ببرید:

pointer
not-allowed
move
text

۳. فیلتر روی عکس (filter)

بدون فیلتر

grayscale

blur

سیاه‌وسفید تا زمان hover

۴. انواع لینک

  • باز شدن در تب جدید (target="_blank")
  • ارسال ایمیل (mailto:)
  • تماس تلفنی (tel:)

۵. عنوان و توضیحات صفحه

به بالای فایل HTML نگاه کنید: تگ title همان چیزی است که در تب مرورگر دیده می‌شود و در نتایج گوگل هم نمایش داده می‌شود. تگ meta با name="description" هم توضیح کوتاه صفحه است. 

<title>آموزشگاه کادوس</title>
<meta name="description" content="آموزش طراحی وب در رشت">
