منویی که در جلسه ۱۴ نتوانستیم بسازیم

در سایت جلسه چهاردهم، منو روی موبایل مجبور بود همیشه باز بماند و چند خط از صفحه را بگیرد. دلیلش این بود که CSS نمی‌تواند یادش بماند که کاربر روی دکمه‌ای کلیک کرده است. حالا با سه خط جاوااسکریپت حلش می‌کنیم.

امتحان کنید: پنجره مرورگر را باریک کنید تا کمتر از ۷۶۸ پیکسل شود (یا F12 بزنید و حالت موبایل را روشن کنید). دکمه ☰ بالای صفحه ظاهر می‌شود؛ روی آن کلیک کنید.

قسمت HTML

<button class="menu-btn" id="menu-btn">☰</button>

<nav class="main-nav" id="main-nav">
    <a href="#">خانه</a>
    ...
</nav>

قسمت CSS

روی موبایل، منو را پنهان می‌کنیم و یک کلاس آماده به نام open می‌سازیم:

@media (max-width: 768px) {
    .menu-btn { display: block; }   /* دکمه ظاهر شود */
    .main-nav { display: none; }    /* منو پنهان شود */
    .main-nav.open { display: flex; } /* مگر اینکه کلاس open داشته باشد */
}

قسمت جاوااسکریپت: فقط ۳ خط

let btn  = document.getElementById("menu-btn");
let menu = document.getElementById("main-nav");

btn.onclick = function () {
    menu.classList.toggle("open");
};
دقت کنید تقسیم کار چطور است: تمام ظاهر منو (رنگ، فاصله، پنهان شدن، باز شدن) در CSS نوشته شده است. جاوااسکریپت فقط یک کار می‌کند: کلاس open را می‌گذارد یا برمی‌دارد. این روش تمیزترین راه کار کردن با این دو زبان است.

چند خط دیگر برای تجربه بهتر

در فایل script.js این صفحه، دو چیز کوچک دیگر هم اضافه شده است: بستن منو بعد از کلیک روی هر لینک، و عوض شدن شکل دکمه از ☰ به ✕ وقتی منو باز است.

متن نمونه برای اینکه صفحه کمی بلند شود و بشود اثر منو را بهتر دید. دبیرستان دانش از سال ۱۳۷۵ فعالیت می‌کند و در سه رشته ریاضی و فیزیک، علوم تجربی و علوم انسانی دانش‌آموز می‌پذیرد.
