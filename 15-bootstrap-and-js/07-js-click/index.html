وقتی کاربر کلیک می‌کند

در جلسه پنجم :hover را یاد گرفتیم: وقتی موس روی چیزی می‌رود، ظاهرش عوض می‌شود. ولی CSS نمی‌تواند بفهمد کاربر کلیک کرده و بعد از آن کاری انجام دهد. این کار جاوااسکریپت است.

الگوی کار

let btn = document.getElementById("my-button");

btn.onclick = function () {
    // هر چه اینجا بنویسیم، با هر کلیک اجرا می‌شود
};

onclick یعنی «هنگام کلیک». آن function یک بسته از دستورهاست که تا وقتی کلیک نشود، اجرا نمی‌شود.

مثال ۱: رنگ پس‌زمینه صفحه را عوض کن

مثال ۲: شمارنده

مثال ۳: نمایش و پنهان کردن

این پاراگراف با کلیک روی دکمه ظاهر و ناپدید می‌شود. در جلسه نهم display: none را یاد گرفتیم؛ اینجا فقط جاوااسکریپت آن را روشن و خاموش می‌کند.

کل کاری که کردیم: فایل script.js این صفحه کمتر از ۲۵ خط است. با همین چند خط، صفحه‌ای که تا دیروز فقط «نگاه کردنی» بود، حالا به کاربر جواب می‌دهد.
