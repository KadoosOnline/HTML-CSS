جلسه پانزدهم جزو سرفصل درس نیست.

جاوااسکریپت چطور صفحه را عوض می‌کند؟

کار جاوااسکریپت با صفحه دو مرحله دارد: اول عنصر مورد نظر را پیدا کن، بعد آن را عوض کن.

مرحله ۱: پیدا کردن با id

در جلسه سوم یاد گرفتیم به هر عنصر می‌شود یک id داد. جاوااسکریپت هم دقیقاً از همان id برای پیدا کردن عنصر استفاده می‌کند: 

let box = document.getElementById("welcome");

یعنی: «در سند (document) دنبال عنصری بگرد که id آن welcome است و آن را داخل جعبه‌ای به نام box بگذار.»

مرحله ۲: عوض کردن

box.textContent = "متن جدید";      // متن داخل عنصر
box.style.color = "red";           // رنگ متن
box.style.backgroundColor = "#fff"; // رنگ پس‌زمینه

این متن قرار است عوض شود
اینجا هم همینطور

امتحان کنید: فایل script.js را باز کنید، متن‌ها را عوض کنید و صفحه را دوباره بارگذاری کنید (F5). دقت کنید که فایل HTML را اصلاً دست نزدیم، ولی صفحه عوض شد.
